# Example Workspace Profile

This compact profile is a comparison aid for discovery and mapping. It is not a
template to copy without checking the target domain.

## Script-to-animation workspace

**Purpose:** turn an approved script into a traceable animation production package.

**Actors:** script owner, visual designer, animator, reviewer, and production owner.

**Stages:**

1. Discover the script, audience, tone, delivery platform, and constraints.
2. Map scenes, assets, dependencies, and review handoffs.
3. Scaffold the workspace with context, asset references, production workflows, and run roots.
4. Design setup questions for brand, dimensions, voice, tools, and optional production paths.
5. Validate references, placeholders, stage handoffs, authority, and acceptance evidence.

**Shared context:** approved script, brand guide, design system, audience profile,
asset inventory, delivery requirements, and tool setup guides.

**Variable examples:** project name, brand name, audience, aspect ratio, visual style,
voice, output platform, and optional captioning or localization stages.

**Acceptance:** every scene and asset has a source or owner, review checkpoints are
named, required tools are verified, and the generated workspace can be promoted without
broken references or unresolved authority questions.
